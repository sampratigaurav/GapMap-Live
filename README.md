This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

1. Copy `.env.local` and set the required values (see **Environment** below).
2. Install dependencies and run the dev server:
   ```bash
   npm install
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) to view the app.

## Environment

Create `.env.local` with:

```
NEXT_PUBLIC_SUPABASE_URL=your-project-url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
GEMINI_API_KEY=your-google-generative-ai-key
```

The app will throw a clear error if the Supabase variables are missing.

## Supabase setup (recreate after deletion)

1. Create a new Supabase project and enable Email/Password auth. (Optional) enable GitHub/Google OAuth and copy the new anon key into `.env.local`.
2. Run this SQL in the Supabase SQL editor to recreate the data model:
   ```sql
   create table if not exists public.roadmaps (
     id bigint generated by default as identity primary key,
     user_id uuid references auth.users(id) on delete cascade,
     target_role text not null,
     current_skills text not null,
     match_percentage numeric,
     missing_skills jsonb,
     actionable_steps jsonb,
     linkedin_url text,
     github_url text,
     verified_skills text[],
     created_at timestamptz default now()
   );

   alter table public.roadmaps enable row level security;

   -- Allow authenticated users to manage their own roadmaps
   create policy "users can manage own roadmaps" on public.roadmaps
     for select using (auth.uid() = user_id)
     with check (auth.uid() = user_id);

   -- Allow public read for portfolio sharing (used by /p/[id])
   create policy "public portfolio read" on public.roadmaps
     for select using (true);
   ```
3. In Supabase Auth → Providers, ensure the site URL matches your deployment (or `http://localhost:3000` locally) so magic links redirect correctly.
4. Update `.env.local` with the new project URL and anon key, then restart `npm run dev`.

## Deploy on Vercel

Deploy with the Vercel Next.js template and add the three environment variables above in the Vercel dashboard.
